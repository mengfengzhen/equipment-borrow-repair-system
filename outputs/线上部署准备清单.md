# 线上部署准备清单

## 推荐目标

最终给面试官一个可以直接打开的系统链接。推荐采用单服务部署：NestJS 后端托管 React 构建产物，页面和接口在同一个域名下。

## 当前项目已具备

- 前端生产构建：`client/dist`
- 后端生产构建：`server/dist`
- API 前缀：`/api`
- Swagger：`/docs`
- 单链接访问：生产环境访问后端根路径即可打开前端页面
- 本地 SQLite：无需单独安装数据库

## 本地模拟生产环境

```bash
npm run setup
npm run build
npm start
```

打开：

- 系统页面：http://localhost:3000
- API：http://localhost:3000/api
- Swagger：http://localhost:3000/docs

## 部署平台需要的配置

环境变量：

```text
JWT_SECRET=请换成长随机字符串
DATABASE_URL=file:./dev.db
CORS_ORIGIN=https://你的线上域名
PORT=平台自动注入或指定端口
```

构建命令：

```bash
npm install && npm run setup && npm run build
```

启动命令：

```bash
npm start
```

## SQLite 注意事项

SQLite 对面试演示足够友好，不需要安装数据库，也方便一键启动。

如果部署平台的文件系统是临时的，服务重启后数据可能丢失。面试演示可以接受这种方式，因为系统会通过 seed 数据恢复演示账号和基础数据。

如果希望长期稳定运行，后续建议改为 PostgreSQL。
